## Environment quirks (do not re-derive)
- **File editor writes new files 0600.** In a Docker image RUN as a non-root user this
  makes them unreadable (`PermissionError: .../demo.py`). Always `chmod 644` new files
  before committing/building.
- **Docker daemon needs `sudo`** in this sandbox; the socket is `root:docker` and the agent
  user is not in the `docker` group. `sudo dockerd &` then `sudo docker ...`. Start it
  **without** `--bridge=none` or builds fail with "network bridge not found".
- CORS mismatch was the real cause of a browser "generation failed": UI origin was
  `127.0.0.1:13000` but `ALLOWED_ORIGINS` only had `localhost:3000`. Exactly the trap
  issue #11 documents.
